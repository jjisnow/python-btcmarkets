# Official reference samples

The obsolete Python 2 samples previously copied here have been removed. They
used legacy authentication, ignored caller parameters and did not run on Python 3.

Current upstream references (do not paste real credentials into examples):

- [Official Python v3 authentication sample](https://github.com/BTCMarkets/api-v3-client-python)
- [API v3 documentation](https://docs.btcmarkets.net/doc/)

Use the maintained `btcmarkets` package in this repository for the read-only
commands described in the root README.
